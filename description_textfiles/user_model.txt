## User Model — Implementation Spec

### Stack
- Framework: FastAPI
- ORM: SQLAlchemy 2.0 (DeclarativeBase style)
- Database: MariaDB 11, accessed via PyMySQL (connection string: mysql+pymysql://)
- Validation / serialization: Pydantic v2 (model_config = {"from_attributes": True})
- DB credentials are read from a .env file via python-dotenv (keys: DB_USER, DB_PASSWORD, DB_HOST, DB_PORT, DB_NAME)

### Database table: `users`
The schema is owned by Alembic migrations (see `alembic/versions/`). The API container runs
`alembic upgrade head` on startup before serving requests. Do NOT use SQLAlchemy's create_all
and do NOT modify the schema by hand — every change must be a new Alembic revision.

Columns:
- id              INT, primary key, AUTO_INCREMENT, starts at 10000
- name            VARCHAR(80), NOT NULL
- role            VARCHAR(20), NOT NULL
- email           VARCHAR(255), NOT NULL
- hashed_password VARCHAR(200), NOT NULL
- log_in_active   INT, NOT NULL, DEFAULT 0, only values 0 or 1 allowed
- last_log_in     DATE, nullable

### SQLAlchemy ORM model (models.py)
Define a class User(Base) with __tablename__ = "users" mapping each column above.
Base is imported from database.py (the shared DeclarativeBase instance).

### Pydantic schemas (also in models.py)
- UserCreate   — request body for creating a user: fields name (str), role (str), email (str), password (str)
- UserResponse — response schema: fields id (int), name (str), role (str), email (str), log_in_active (int), last_log_in (Optional[date])
  hashed_password must NOT appear in UserResponse.

### Database session (database.py)
- Build the DATABASE_URL from env vars at module load time.
- Provide a get_db() generator function (yield pattern) to be used as a FastAPI dependency.
- SessionLocal is created with autocommit=False, autoflush=False.

### API endpoints (routers/auth.py)
Router prefix: /auth
Tags: ["auth"]
Included in the FastAPI app via app.include_router(auth.router) in main.py — no extra prefix.

Endpoints:

GET /auth/users
- Returns a list of all users (List[UserResponse]).
- Queries the full users table, no filtering.

POST /auth/users
- Accepts a UserCreate body.
- Hashes the password field using SHA-256 (hashlib.sha256(password.encode()).hexdigest()) before storing.
- Rejects duplicate names with HTTP 400 "username already exists".
- Returns the created user as UserResponse with HTTP 201.

### Password hashing
Use Python stdlib hashlib.sha256 — no external password library. Store the hex digest in hashed_password.
